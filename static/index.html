独立 401 重登录工具

独立账号库 · 独立代理池 · 默认密码 + 2FA 登录 · 支持 Sub2API JSON

这是独立工具，不读取主项目的账号库或代理池。所有导入的密码、TOTP、AT/RT/ID 和代理都会保存在本工具的本地 SQLite 中，请只在可信网络使用。
三段格式 邮箱----密码----2FA：登录时由 OpenAI 返回的空间列表决定，使用第一个空间；适合只有一个空间或不要求固定空间的账号。
四段格式 邮箱----密码----2FA----workspace_id：强制选择指定 Workspace，适合一个账号属于多个空间的情况；不会随机选择。
同邮箱重复导入会合并非空字段；账号库会保留已保存的 Workspace ID。密码+2FA 导出仍是三段格式，如需固定空间请使用四段格式重新导入。
